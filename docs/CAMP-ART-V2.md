# Arte del campamento v2

Ocho composiciones generadas con la herramienta integrada de imágenes, a partir de la captura del campamento como referencia de estilo. Las composiciones son ilustraciones ambientales. Las capturas de productos y los certificados se incorporan mediante el proceso editorial de cada caso.

## Prompt compartido de escritorio

> Use case: stylized-concept. High quality illustrated game room backdrop for Alejo's mountain camp portfolio. Use the input as style reference. Match the rich crisp hand-crafted pixel-art illustration, warm sun, turquoise, moss and amber palette, fine material details and three-quarter perspective. No oversized coarse pixel blocks, blur, UI panels, lettering, logos or people. Wide 3:2 composition with the main object centered. Leave the lower central foreground as uncluttered floor for the character. Light from upper left.

| Sala | Descripción añadida al prompt |
| --- | --- |
| Taller | Wooden cabin with rafters, climbing plants and windows toward the mountain lake. Central drafting desk, two separate blank blueprints, brass tools, turned-away monitor and stool. |
| Carpa | Cream canvas tent, open flap toward the lake, camp bed, leather backpack and lantern. Central writing table with blank notebook, pen and mug. Calm foreground rug. |
| Bitácora | Open-air reading nook under a pergola. Central oak lectern, open journal, compass, books and pressed flowers. Ivy, lake and deck. |
| Radio | Open timber shelter with a teal and brass shortwave transceiver, microphone, tuning knobs, envelope, lantern and lake behind the central desk. |

## Prompt de retrato

> Use case: precise-object-edit. Create a portrait 2:3 composition of this same camp room for a mobile game backdrop. Recompose the room rather than cropping or stretching it. Show the full central table and its main object in the middle third. Preserve materials, lighting, detail, lake and palette. Keep upper 20% and lower 25% relatively calm for HTML overlays. No people, text, UI or logos.

La referencia de cada retrato fue su propio interior de escritorio. Los PNG originales se exportaron a WebP con calidades 87 y 84, respectivamente. Los ocho archivos finales viven en [camp-rooms-v2](../public/assets/camp-rooms-v2/).
