# Iconos de interfaz

14 SVG originales de Lucide, descargados de su repositorio oficial. Geometría y dimensiones conservadas; cada uno usa una caja de 24 × 24.

| Archivo | Uso sugerido |
| --- | --- |
| `map.svg` | Campamento / mapa |
| `book-open.svg` | Bitácora / trayectoria |
| `briefcase-business.svg` | Proyectos / experiencia |
| `mail.svg` | Contacto |
| `download.svg` | Descargar CV |
| `x.svg` | Cerrar |
| `volume-2.svg` | Sonido habilitado |
| `volume-x.svg` | Sonido deshabilitado |
| `arrow-up.svg` | Dirección arriba |
| `arrow-down.svg` | Dirección abajo |
| `arrow-left.svg` | Dirección izquierda / volver |
| `arrow-right.svg` | Dirección derecha / avanzar |
| `external-link.svg` | Abrir enlace externo |
| `menu.svg` | Navegación compacta |

Conservar `LICENSE-lucide.txt` al distribuir los SVG. Procedencia y hashes en `sources.json`.

Usar estos iconos funcionales en los controles; el escenario mantiene su arte pixel. Los enlaces a GitHub y LinkedIn pueden llevar una etiqueta de texto y `external-link.svg`.
